# Créditos do personagem

- **Modelo base**: "HairSample_Male", modelo de exemplo do VRoid Studio (pixiv Inc.).
  Licença **CC0** (domínio público): uso comercial, edição e redistribuição livres.
  Ver https://vroid.pixiv.help/hc/en-us/articles/4402614652569
- Cópia usada: github.com/madjin/vrm-samples (`vroid/beta/HairSample_Male.vrm`).
- Modificações (tools/blender/build_hero.py, no Blender): roupas removidas, traje azul-marinho de gola
  alta pintado (costuras e emblema original), pés descalços, cabelo branco, olhos cinza, pinta no rosto,
  animações criadas como Actions. Arquivo editável: `art/character/hero.blend`; o jogo carrega `hero.glb`.
